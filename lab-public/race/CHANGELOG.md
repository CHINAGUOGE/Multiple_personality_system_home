## [v1.6.2] — 2026-06-06 (当前版本)

## [v1.4.1] — 2026-06-06

### 修复

- **商店抽取概率修正（P2）**：原 `pickWeightedParts` 对每件零件赋稀有度权重，导致某稀有度实际占比被其零件数量放大/稀释，与图鉴展示的出现率不一致。改为先按 `PART_RARITY_WEIGHTS` 抽稀有度桶、再桶内等概率抽零件，去重后首抽分布精确等于配置出现率。 (ea87ab0)
- **赛道面板内边距**：调整内边距防止车号文本被截断。 (d1e4381)
- **重开难度重置**：重开时重置难度为默认值。 (628d242)
- **失败判定逻辑**：修复应失败检查使用最低难度报名费而非当前难度的问题。 (c9d7db0)
- **难度按钮文字重影**：修复难度按钮文字重影问题。 (857be7f)
- **空格键操作**：调整 v1.4.1 平衡性与空格键交互。 (4374494)

### 新增

- **神话级零件补全**：为 Tire / 变速箱 / 进气 / 排气 / 稳定件五种类型各新增一个神话零件。 (c9d7db0)
- **报名费不足提示优化**：区分是否可通过降难度解决，给出相应提示。 (c9d7db0)

### 优化

- **难度选择改为伪弹窗**：赛事页只保留「当前难度 + 更改难度」按钮，点击弹出复古风格难度选择弹窗，移动端不再大面积平铺。选择后自动关闭并联动电脑强度；比赛锁定阶段禁用并自动收起。 (7ef3864)
- **困难模式对手强度**：提高困难模式对手强度系数。 (d190c06)
- **报名费按难度缩放**：报名费按难度缩放，并调低商店稀有度爆率。 (f583edb)
- **favicon 更新**：更新赛车页 favicon。 (7b1eb45)

## [v1.4] — 2026-06-06

### 新增

- **难度分级**：5 档（休闲 / 标准 / 挑战 / 专家 / 噩梦），默认 normal，写入存档，比赛中锁定。人机强度引入随局数成长曲线并叠加难度倍率，奖金乘 rewardMultiplier。 (63879df)

- **奖池按难度变化**：`LOOT_POOLS` 限定稀有度范围，商店概率仅由奖池+权重决定（dropRateMultiplier 不参与商店概率，预留比赛掉落系统）。 (63879df)
- **稀有度 5 档**：common / rare / epic / legendary / mythic，旧 uncommon 重归类保留。 (63879df)
- **改装件扩展**：新增 10 件带副作用改装件（3 mythic / 3 legendary / 4 epic）。 (63879df)
- **自动保存**：结算 / 购买 / 装备 / 出售 / 刷新商店 / 切换难度后安全保存，失败仅写日志。 (63879df)

### 兼容

- **旧存档兼容**：无 difficulty 回退 normal，uncommon 迁移 rare，其他未知回退 common。 (63879df)

### 优化

- **移动端 360px**：5 格导航不溢出，难度按钮与图鉴卡片单列/换行。 (63879df)
