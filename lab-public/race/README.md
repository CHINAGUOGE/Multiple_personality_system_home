# 横线赛车经营赛

> MPS Lab 下的复古 Windows 风格网页赛车经营小游戏。

## 项目概览

- 线上路径：`https://lab.mpsteam.cn/race/`
- 目录位置：`lab-public/race/`
- 当前版本：`v1.5`
- 页面类型：纯静态页面，无需额外打包，可直接随 Lab 子站发布

这个目录是一套可独立运行的小游戏资源，核心玩法是：

- 报名比赛，等待绿灯起步
- 通过反应速度和车辆属性争取更高名次
- 用奖金购买随机零件
- 在改装、图鉴、档案页持续经营车辆

## 玩法特色

| 模块 | 说明 |
| --- | --- |
| 赛事 | 红灯 / 黄灯抢跑判负，绿灯后起步，考验反应与车辆性能 |
| 难度 | 提供休闲、标准、挑战、专家、噩梦 5 档难度，影响报名费、奖金倍率与电脑强度 |
| 商店 | 随机刷新零件，已拥有零件权重会降低，减少重复刷出 |
| 改装 | 支持装备、替换、卸下零件，车辆属性会实时变化 |
| 图鉴 | 合并库存与图鉴，支持全部 / 已拥有 / 未拥有 / 当前奖池筛选 |
| 档案 | 展示成就、统计、难度入口、保存 / 读取 / 重开清档、版本信息 |

## 文件结构

```text
lab-public/race/
├─ index.html          # 页面结构与 UI 容器
├─ style.css           # 复古桌面风格与响应式样式
├─ game.js             # 入口脚本，顺序加载 scripts/ 下模块
├─ favicon.ico         # 页面图标
└─ scripts/
   ├─ config.js        # 常量、难度、奖池、零件配置
   ├─ state.js         # 全局状态与 DOM 引用
   ├─ core.js          # 页面切换、渲染、通用逻辑、自动保存
   ├─ race.js          # 比赛流程、起步判定、奖励结算
   ├─ achievements.js  # 成就、统计、档案页渲染与提示
   ├─ parts.js         # 商店、改装、图鉴逻辑
   ├─ storage.js       # 本地存档读写与重开
   └─ main.js          # 事件绑定与初始化入口
```

## 本地预览

如果只是快速查看页面，直接打开 `lab-public/race/index.html` 即可。

如果要按仓库正式方式联调 Lab 子站，使用：

```bash
npm run build:lab
```

构建后内容会输出到 `dist-lab/`，其中本目录对应线上 `/race/` 路径。

## 开发说明

### 交互与存档

- 存档使用浏览器 `localStorage`
- 键盘快捷操作：电脑端可用空格键执行报名 / 起步 / 下一场
- 比赛进行中禁止读取、保存和重开，避免状态损坏

### 修改建议

- 调整玩法数值：优先修改 `scripts/config.js`
- 调整比赛流程：修改 `scripts/race.js`
- 调整商店、改装、图鉴：修改 `scripts/parts.js`
- 调整成就、统计、档案：修改 `scripts/achievements.js`
- 调整整体 UI：修改 `style.css` 与 `index.html`

### 注意事项

- `game.js` 负责按顺序加载脚本，新增脚本时要同步维护加载列表
- 本目录属于 Lab 子站静态资源，不应影响主站 `src/` 的构建流程
- 涉及构建配置时，需要区分主站 `npm run build` 与 Lab `npm run build:lab`

## 维护目标

这个小游戏目前更接近一个可持续迭代的原生 Web 小项目，后续如果扩展内容，建议优先保持这几个方向：

- 继续维持“单目录可运行”的结构，降低迁移和部署成本
- 新增功能时优先沿用现有分层，不要把所有逻辑重新塞回一个文件
- UI 可以继续增强，但应保留当前复古桌面和轻经营的产品气质
