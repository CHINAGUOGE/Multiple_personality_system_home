# 小旅猫图片素材清单

> v0.1 不依赖这些图片上线。当前版本先用 CSS 轻量猫和卡片视觉跑通玩法；下面素材可在 v0.2 之后逐步替换或增强。

## 优先级 A：最值得先做

- 小旅猫主视觉：透明背景，坐在窗边或纸箱旁，适合放在小屋区域。
- 小屋背景：窗台、软垫、小纸箱、墙面小装饰，横版和移动端裁切都能用。
- 明信片底图模板：空白边框、轻微纸张纹理，方便叠加路线标题和描述。
- 纪念品小图标：漂亮羽毛、半张车票、小贝壳、圆石子、旧纽扣、钥匙圈。

## 优先级 B：路线氛围图

- 近处屋顶：屋檐、天空、晾衣绳或小花盆。
- 河边小路：慢水、草坡、小桥。
- 雾气森林：树影、薄雾、落叶。
- 旧车站：站牌、长椅、旧时刻表。
- 海边防波堤：海风、堤岸、远处灯塔。
- 雪后巷子：积雪、墙角、脚印。

## 优先级 C：UI 点缀

- 露珠图标：用于庭院和余额。
- 小鱼干图标：用于食物卡片。
- 铃铛、地图、围巾、折叠垫、玻璃瓶图标：用于道具卡片。
- 爪印分隔符：用于收藏册或空状态。

## 建议规格

- 主视觉：`1200x800` 或更大，保留主体完整轮廓。
- 路线图：`1600x900`，横图优先，移动端可居中裁切。
- 图标：透明背景 PNG 或 SVG，建议 `512x512` 源文件。
- 风格：清爽、低压力、现代轻量，不要复刻任何现有旅行放置游戏的角色、美术或 UI。
