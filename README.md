# MPS Team CN 官网

> 基于 Astro 的多意识体科普与社区官方网站

## 技术栈

- **框架**: Astro 4.x + TypeScript
- **样式**: Tailwind CSS + CSS Variables
- **部署**: Cloudflare Pages
- **质量**: ESLint + Prettier + Stylelint + Markdownlint

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview

# 代码检查
npm run lint

# 自动修复
npm run lint:fix
```

## 项目结构

```
.
├─ public/                 # 静态资源
├─ src/
│  ├─ content/             # 内容片段
│  ├─ layouts/             # 页面布局
│  ├─ components/          # 组件
│  ├─ pages/               # 页面路由
│  ├─ styles/              # 全局样式
│  └─ utils/               # 工具函数
├─ scripts/                # 构建脚本
└─ astro.config.mjs        # Astro 配置
```
